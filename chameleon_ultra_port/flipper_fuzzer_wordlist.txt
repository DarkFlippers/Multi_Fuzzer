# =============================================================================
#  Wordlista UID wyciagnieta z aplikacji "Multi Fuzzer" dla Flipper Zero
#  Zrodlo: lib/worker/protocol.c  (tablice zaszyte na sztywno w kodzie C)
#
#  Format: jedna linia = jeden UID zapisany w HEX (bez spacji, wielkie litery).
#  Linie zaczynajace sie od '#' sa komentarzami (tak jak w oryginalnym workerze
#  Flippera: fuzzer_worker.c pomija linie zaczynajace sie od '#').
#
#  UWAGA o przenosnosci na Chameleon Ultra:
#   - Sekcja EM4100 (5 bajtow) -> emulacja LF EM410x na Chameleon Ultra (bezposrednio).
#   - Sekcja 4BYTE (4 bajty)   -> uzyteczna jako UID dla HF MIFARE Classic (4-bajtowy
#                                 UID). ATQA/SAK NIE wystepuja w kodzie Flippera,
#                                 wiec skrypt dokleja domyslne wartosci MIFARE 1K.
#   - iButton (DS1990/Cyfral/Metakom) to protokoly Dallas 1-Wire, ktorych
#                                 Chameleon Ultra nie emuluje - zalaczone tylko
#                                 jako kompletny zrzut danych zrodlowych.
# =============================================================================
